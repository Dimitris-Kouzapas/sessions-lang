# sessions

This repository contains the reference implementation of **sessions**, a prototype executable language for multiparty session programming.

## Requirements

- Go
- Java, only needed to regenerate the parser

## Tested Environment

The artifact has been tested with Go 1.26.3. Parser generation has been tested with Java 25.0.3 and the ANTLR library included in `lib/antlr-4.13.2-complete.jar`.

The repository already includes the Go code generated by ANTLR.

## Building

Build the tool:

Unix/macOS:

```bash
go build -o sessions .
```

Windows:

```powershell
go build -o sessions.exe .
```

Regenerate the parser only after modifying the grammar:

```bash
java -jar lib/antlr-4.13.2-complete.jar -Dlanguage=Go -no-listener -visitor ast/parser/sessions.g4
```

## Usage

Run a program:

```bash
./sessions path/to/program.sess
```

On Windows, use `.\sessions.exe` instead of `./sessions`.

By default, the tool type checks the program and then executes it.

### Flags

```text
-v,  --verbose      Enable verbose mode
-a,  --analysis     Enable analysis mode
-ne, --no-exec      Disable execution
-p,  --prettyPrint  Pretty-print the program
-u,  --usage        Print usage
```

Examples:

```bash
./sessions -ne esop27_submission_examples/login.sess
./sessions -p esop27_submission_examples/login.sess
./sessions -v esop27_submission_examples/login.sess
./sessions water_network/control.sess
```

## Examples

The repository contains executable examples, including:

- examples from the ESOP 2027 submission paper;
- small examples and tutorials;
- higher-order programs;
- worker topologies;
- water-network control configurations.

## Notes

The implementation maps processes to Go goroutines, session communication to unbuffered Go channels, and shared-name initiation to runtime brokers.
